## 🇧🇷 Sobre o repositório

Este repositório reúne meus **estudos em JavaScript intermediário**, com foco na prática e na construção de projetos que simulam desafios reais do desenvolvimento front-end.

O objetivo principal foi **dominar a interação entre JavaScript e HTML**, escrever código mais limpo e compreender conceitos essenciais usados no mercado, como manipulação do DOM, arrays avançados e consumo de APIs.

Todo o conteúdo foi desenvolvido ao longo de um plano de estudos estruturado em semanas, com exercícios, mini-projetos e projetos práticos.

# 🇺🇸 Intermediate JavaScript Studies

## About this repository

This repository contains my **intermediate JavaScript studies**, focused on hands-on practice and building projects that simulate real front-end development challenges.

The main goal was to **master the interaction between JavaScript and HTML**, write cleaner code, and understand essential concepts used in the job market, such as DOM manipulation, advanced arrays, and API consumption.

All content was developed following a structured weekly study plan, including exercises, mini-projects, and practical projects.
